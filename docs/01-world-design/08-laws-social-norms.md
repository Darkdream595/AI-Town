# 法律与社会规范

## 1. 目的

定义洛文王国法、重开宪章、镇规和组织章程的层级，明确财产、暴力、魔法、森林与矿务行为边界，并把社会习惯与可执行法律区分开。

## 2. 非目标

本文件不定义协议权限位、罚金公式、证据数据库、战斗合法性算法或完整司法模拟；不把失礼自动处理为犯罪，也不允许模型文本自行定罪、扣款、拘押或改变 Spell 法律状态。

## 3. 术语与定义

| 术语 | 定义 |
|---|---|
| 王国法 | 最高地方适用法，包含人身安全、重大财产犯罪、王道和宪章边界 |
| 镇规 | 镇务议会在宪章授权内发布的公共空间、营业、建设与地方税规则 |
| 组织章程 | 只约束自愿成员和组织资源的内部规则，不得对抗上位法 |
| 法律状态 | 行为或法术的 `permitted`, `restricted`, `prohibited` 分类 |
| 正当防卫 | 面对正在发生且相称的威胁所采取的最小必要行动 |
| 社会规范 | 违反后主要产生解释、道歉或关系影响，不自动形成法律处罚 |
| 程序保障 | 告知理由、记录证据、回避利益冲突和提供复核路径 |

## 4. 规则与不变量

| ID | 规则 |
|---|---|
| `REQ-WORLD-024` | 所有地方规则必须按王国法 > 重开宪章 > 镇规 > 组织章程解析，冲突时下位规则失效。 |
| `REQ-WORLD-025` | 对违法行为的响应必须基于已提交事实、管辖、严重度与程序保障，不得按族裔、文化或信仰推定责任。 |
| `REQ-WORLD-026` | 每个 `SpellDefinition` 必须引用法律状态；受限施法明确场所、许可、目标同意或紧急例外。 |
| `REQ-WORLD-027` | 社会规范必须产生可解释关系反馈，但不能自动扣除货币、物品、HP 或自由。 |
| `RULE-WORLD-031` | 无王冠溪镇首版死刑；正式居民的最严重失败后果是重伤、赔偿、许可暂停、临时羁押、被俘或移交审理。 |
| `RULE-WORLD-032` | 镇长、守卫、组织负责人和普通居民均受同一证据与冲突回避规则。 |
| `RULE-WORLD-033` | 私人住宅、私人容器、个人 Secret 与身体治疗默认需要所有者/当事人同意，紧急救命例外必须记录。 |
| `RULE-WORLD-034` | Illusion 不得用于伪造身份、同意、证据或商品；攻击性 Elemental/Spirit 法术在镇区公共空间为 prohibited。 |
| `RULE-WORLD-035` | 森林禁采圈、矿洞封锁线和建筑许可是结构化管辖数据，视觉标识缺失不使限制失效。 |

## 5. 数据与接口

`DES-WORLD-008`：发布 `LegalContext` 分类矩阵：

| 严重度 | 示例 | 初始响应 | 可用后果 |
|---|---|---|---|
| `social` | 插队、失约、无礼称谓 | 解释、拒绝、调解 | 道歉、关系变化 |
| `civil` | 未履行交易、轻微财损、越界采集 | 记录、调解、估价 | 返还、赔偿、服务义务 |
| `municipal` | 无许可施工、阻塞道路、违规营业 | 镇务调查 | 罚款、停工、许可暂停 |
| `criminal` | 袭击、盗窃、纵火、危险禁术 | 守卫保护现场并调查 | 赔偿、临时羁押、移交 |
| `emergency` | 正在发生的火灾、坍塌、袭击 | 先救援与制止 | 事后复核、必要费用 |

具体金额、时限、Command 和证据 Schema 由 ECON、PLAYER、BACKEND 与 EVENT owner 定义。

## 6. 正常流程

1. 报告或观察形成 allegation，不等于事实。
2. 溪桥守卫或有管辖组织保护现场、记录已提交事件和可访问证据。
3. 依据地点、行为、Spell 法律状态、同意和紧急性分类。
4. 当事人可说明、出示证据或请求回避；镇长不能审理自身利益冲突。
5. 合法 Command 提交返还、赔偿、许可变化或临时羁押，并产生可复核事件。
6. 居民基于所知形成 Belief 与关系反应；判定结果不强制所有人相信。

共同社会规范包括：进门先示意、矿洞同行核名、共享炖锅先留值勤者份额、谈及灰脉灾变先确认对方是否愿意、称呼优先使用自报姓名与职务。公共通用语为王国通用语。

## 7. 边界情况

- 正当防卫结束后继续攻击不再受防卫保护，按新行为单独判断。
- 紧急治疗可在无法取得同意且存在即时生命风险时进行，必须记录原因且不授权读取私人记忆。
- 谣言可以触发调查，不能单独满足处罚证据。
- 未成年人不是首版正式居民专门状态；任何后续新增都必须先扩展内容边界和程序保障，不能靠现有规则猜测。
- 外来商队适用公共安全与交易法，但不因此成为第四地区或正式居民。

## 8. 错误与降级

管辖未知、证据 Revision 过期、规则冲突或处分超权限时返回 `WORLD_LEGAL_REVIEW_REQUIRED`，不部分扣款或拘押。模型不可用时，紧急响应按确定性安全预案执行，非紧急裁定延期。缺少视觉告示时通过交互提示展示结构化限制。

## 9. 安全与性能

法律记录对公开裁定、受限证据和私人陈述分级访问。举报文本按纯文本和输入限额处理。法律矩阵、管辖区和 Spell 状态按版本缓存；每次提交仍在最新 Revision 校验，不能用缓存越权。

## 10. 验收标准

- 四层规范冲突测试总能选出唯一有效规则或明确拒绝。
- 相同行为在相同事实下不因 ancestry、culture 或 faith 改变法律分类。
- permitted/restricted/prohibited 三类法术均有可执行示例和拒绝路径。
- 社会失礼只影响对话/关系，不直接修改资产、HP 或拘押状态。
- 镇长利益冲突、谣言举报、紧急治疗和视觉告示缺失均有确定处理。
