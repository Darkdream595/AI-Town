# 王国、组织与派系

## 1. 目的

定义洛文王国对王冠溪镇的上级权威、重开宪章下的自治机构、行会、信仰团体和利益张力，为镇长权限、居民归属、事件选择和社会冲突提供稳定组织语义。

## 2. 非目标

本文件不定义完整王国地图、现任王室姓名、组织成员数据库、投票 UI、预算公式或 Event 状态机；不要求 8–12 名正式居民独自承担所有背景岗位。背景办事员可以抽象存在，但关键交互岗位必须由正式居民或明确服务节点承担。

## 3. 术语与定义

| 术语 | 定义 |
|---|---|
| 洛文王国 | `polity.rowen_kingdom`，王冠溪镇所在的封建法权上级 |
| 重开宪章 | 授予镇区预算、公共工程、有限税率和地方治安权的王室文书 |
| 镇务议会 | 由镇长、居民席位与行业观察席组成的地方议事机构 |
| 组织 | 有章程、成员、资源与公开职责的持久社会实体 |
| 派系 | 围绕具体利益形成的立场集合，可跨组织且不等于秘密结社 |
| 管辖权 | 某组织可合法调查、命令或处分的行为与地区范围 |

## 4. 规则与不变量

| ID | 规则 |
|---|---|
| `REQ-WORLD-017` | 镇务治理必须区分王国保留权、重开宪章自治权、组织内部权与私人权利。 |
| `REQ-WORLD-018` | 首版必须登记镇务议会、溪桥守卫、行旅行会、银烬合作社、七灯礼拜所和溪林守誓会。 |
| `REQ-WORLD-019` | 派系冲突必须围绕可实现的资源、法律、风险或记忆分歧，不使用绝对善恶阵营。 |
| `REQ-WORLD-020` | 组织成员身份必须影响可知信息、请求与义务，但不能自动授权读取个人 Secret 或绕过 owner 规则。 |
| `RULE-WORLD-022` | 王国保留边境军事、王道、重大刑案与宪章撤销权；镇区拥有公共预算、地方税率、道路、建筑许可、节庆和日常治安权。 |
| `RULE-WORLD-023` | 镇长单独命令不能没收私人财产、强制感情、判定重大刑案或改写组织内部信念。 |
| `RULE-WORLD-024` | 任一组织不得同时拥有调查、裁判和不可申诉处罚三项完整权力。 |
| `RULE-WORLD-025` | 派系立场由事件、资源和成员解释驱动；组织不能被模型整体瞬间改变态度。 |
| `RULE-WORLD-026` | 信仰团体只拥有自愿礼仪、照护与内部承诺权，不拥有普遍施法豁免或强制皈依权。 |

## 6. 正常流程

1. 问题先按发生地与行为类型定位管辖组织。
2. 组织通过公开请求、成员承诺、排班或议会提案动员居民。
3. 涉及多个 owner 时，镇务议会协调预算与权限，专业组织提供证据和执行能力。
4. 决议生成已登记 Command/WorldEvent；受影响居民依据自身知识和关系接受、反对、协商或退出。
5. 结果通过公告、组织声誉、资源变化和后续派系立场反馈。

当前三条张力轴为：矿洞复开速度 vs. 安全支护、森林采集收益 vs. 盟誓再生边界、王国监督稳定性 vs. 地方自治效率。每条都允许折中、失败与立场变化。

## 7. 边界情况

- 同一居民可同时属于行会与信仰团体；具体事件中的角色冲突必须显式记录，不能自动选择组织忠诚。
- 镇长也是争议当事人时，相关处分由议会代理席或巡回法庭处理。
- 组织暂时无人担任关键岗位时，服务进入降级排班或委托状态，不赋予玩家无条件权限。
- 派系秘密只向有相应 ACL 的成员提供；组织公开立场不等于所有成员私人意见。
- 王国命令作为背景事件进入时，仍必须映射为注册 Event Template，不能由 lore 文本直接改状态。

## 8. 错误与降级

未知组织 ID、越权命令或管辖冲突返回 `WORLD_JURISDICTION_DENIED`，不部分执行。表决 AI 不可用时，保留已提交立场并延后非紧急议程；紧急疏散按本地确定性预案执行。缺少关键成员时使用公开服务节点，不伪造私人记忆或签名。

## 9. 安全与性能

组织投影遵守最小披露：公开章程、公开职务和已授权 faction 信息分开提供。成员名单与立场按 Revision 缓存，不在每 Tick 重新生成。组织权力必须通过 Command 权限矩阵和审计事件验证，模型描述无授权效果。

## 10. 验收标准

- 六个组织均具有职责、管辖、权限边界和至少一个可触发请求。
- 镇长尝试没收私人财产、强制关系或裁决重大刑案时被拒绝。
- 三条张力轴各可产生至少两方合理立场与一条折中路径。
- 双重成员身份、回避、关键岗位空缺和模型故障均有确定处理。
- 组织 Secret 不会进入非成员 DecisionContext。
