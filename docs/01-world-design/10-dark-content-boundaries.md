# 黑暗内容与后果边界

## 1. 目的

定义克制的暗黑幻想内容范围，明确正式居民非永久死亡、受伤、被俘、背叛、诅咒与债务的可持续后果，使失败具有重量而不依赖猎奇、永久删除或无成本复位。

## 2. 非目标

本文件不定义 HP、伤害、治疗、关系或债务公式，不替代 DIALOGUE 的输入安全和 COMBAT 的结算规则。首版不表现露骨肢解、性暴力、虐待细节、仇恨宣传或以儿童受害制造刺激，也不建立正式居民永久死亡路线。

## 3. 术语与定义

| 术语 | 定义 |
|---|---|
| 克制暗黑 | 通过威胁、损耗、选择代价与余波表达危险，而非持续血腥或绝望 |
| 正式居民 | 首版 8–12 名核心 Resident 及采用同一正式居民生命周期的玩家角色 |
| 非永久失败 | HP 归零或叙事失败后转入可恢复但有成本的状态，不删除 Resident aggregate |
| 余波 `Aftermath` | 危机结束后处理伤病、债务、信任、修复与责任的持续阶段 |
| 背叛 | 对已记录 Commitment、共享秘密或明确协定的故意违反 |
| 被俘 | 角色失去行动自由但仍保留身份、状态、位置引用和解救/协商路径 |
| 内容强度 | `implied`, `restrained`, `forbidden` 三档表现许可 |

## 4. 规则与不变量

| ID | 规则 |
|---|---|
| `REQ-WORLD-032` | 正式居民和采用正式居民生命周期的玩家 HP 归零后，只能进入昏迷、重伤、撤退或被俘等非永久状态。 |
| `REQ-WORLD-033` | 重伤、被俘、背叛、诅咒和债务必须分别定义状态、可见反馈、恢复路径与最小成本。 |
| `REQ-WORLD-034` | 暗黑内容必须通过内容强度矩阵审查，禁止项不能由 Prompt、Event 或玩家输入绕过。 |
| `REQ-WORLD-035` | 每个重大危机必须进入 Aftermath，并允许治疗、赔偿、营救、和解、调查或长期适应中的至少一种可执行响应。 |
| `RULE-WORLD-041` | 正式 Resident aggregate 不得永久删除、写入 death terminal state 或以同名新角色替换。 |
| `RULE-WORLD-042` | 普通魔物、召唤物与非居民敌人可以死亡或消散，但表现仍受强度矩阵约束。 |
| `RULE-WORLD-043` | 非永久失败不能自动满状态复位；至少消耗 GameTime、资源、许可、关系修复或风险中的一项。 |
| `RULE-WORLD-044` | 被俘不允许无限期无状态停留，必须登记持有方、地点、复核时间和至少一个退出条件。 |
| `RULE-WORLD-045` | 背叛必须基于已知 Commitment 或协定，不能仅因模型把不同意见描述为“背叛”就触发机械后果。 |
| `RULE-WORLD-046` | 创伤、信仰、族裔和疾病不得被用作羞辱性笑料或推定邪恶的依据。 |

## 5. 数据与接口

`DES-WORLD-010`：内容与后果矩阵：

| 主题 | 允许表现 | 禁止表现 | 最小恢复/余波 |
|---|---|---|---|
| 受伤 | 包扎、疲惫、少量非写实血迹、行动受限 | 露骨器官、肢解特写、痛苦施虐 | 治疗资源 + GameTime 或技能限制 |
| 被俘 | 看守、谈判、营救、交换、逃脱 | 性剥削、酷刑细节、无限期无状态拘押 | 关系/资源/风险代价 + 复核 deadline |
| 背叛 | 违约、泄密、抛弃职责及信任下降 | 把普通拒绝或文化差异自动定为背叛 | 解释、赔偿、重建承诺或关系长期改变 |
| 诅咒 | 梦魇、能力限制、环境异常、调查线索 | 不可逆人格抹除、以精神疾病污名化 | 研究、仪式/法术、代价选择或适应 |
| 债务 | 账目、延期、工作偿还、合法追索 | 债务奴役、身份世袭、任意没收 | 分期、服务、协商或合法清偿 |
| 非居民敌人死亡 | 抽象倒地、淡出、残留物 | 尸体玩弄、血腥特写 | 战斗 Aftermath 与必要清理 |

COMBAT、RESIDENT、MEMORY、ECON 与 EVENT owner 分别实现数值和状态；本表只拥有内容许可与后果语义。

## 6. 正常流程

1. 危险事件在激活前声明内容主题和最大强度。
2. 战斗或事件由确定性 owner 结算；模型只能从合法行动和表达范围选择。
3. 正式居民遭受致命数值时，根据地点、对手、盟友和逃生条件选择昏迷、重伤、撤退或被俘。
4. 提交状态、责任、可见表现和相关 `DomainEvent`，进入 Aftermath。
5. 居民与玩家通过治疗、营救、偿还、调查、赔偿或协商处理后果。
6. 恢复达到 owner 条件后解除限制，但保留合理记忆、关系与历史事件。

## 7. 边界情况

- 全队失败时，可分别进入重伤、撤退或被俘，不要求所有人同一结果；世界仍保留救援路径。
- 持有方失效或场景不可达时，被俘状态转入已登记安全复核流程，不能删除角色。
- 玩家要求露骨描述时，系统保持事件事实并以克制摘要回应。
- 模型把未兑现但尚未到期的承诺称为背叛时，不触发背叛状态。
- 恢复资源不足时，限制可延长并产生求助机会，但不得永久锁死核心玩法。

## 8. 错误与降级

出现 forbidden 内容标签、正式居民 death terminal、无退出条件的 captivity 或零成本恢复时，内容/状态提交返回 `WORLD_CONTENT_BOUNDARY_VIOLATION`。模型不可用时使用确定性的昏迷、撤退和安全 Aftermath 模板。视觉资产过强时降级为抽象倒地、遮挡或淡出，规则结果不变。

## 9. 安全与性能

所有生成 Prompt 携带内容标签与最大强度；玩家文本不能提升上限。日志只记录分类、stable ID 与结果，不复制有害文本或详细创伤描述。内容校验必须在模型输出和 Event render 两个出口执行，且不可被低性能模式关闭。

## 10. 验收标准

- 正式居民在战斗、灾害和脚本事件三条路径均无法进入永久死亡或删除。
- 五类长期后果各有状态、反馈、退出条件和非零成本。
- forbidden 提示、玩家请求和 Event 参数均被双出口校验拒绝。
- 全队失败、持有方失效、资源不足和模型离线时仍有可恢复状态。
- Aftermath 中的历史、记忆与关系不因身体恢复被自动清除。
