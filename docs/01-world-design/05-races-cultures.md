# 族裔与文化

## 1. 目的

定义首版可用于玩家与正式居民身份的四类族裔、王冠溪镇的混合文化、语言约定与表现边界，确保文化差异可进入日程、礼仪、服装和冲突，但不把性格、职业或道德绑定到血统。

## 2. 非目标

本文件不定义 Resident 属性数值、角色创建 UI、语言判定算法、具体服装 Asset 或关系公式；不建立现实民族的一一对应，也不把任何族裔设为天生邪恶、天生高贵或固定职业。

## 3. 术语与定义

| 术语 | 定义 |
|---|---|
| 族裔 `ancestry` | 可见生理特征与家族来源的身份维度，不等于文化、国籍或价值观 |
| 文化 `culture` | 通过家庭、地区、组织和经历习得的礼仪、技艺、饮食、语言与观念 |
| 王冠溪混合文化 | 围绕河运、林地盟誓、矿业互助和自治重建形成的本地生活方式 |
| 传承语 | 家庭或社群使用的语言；不自动为同族裔所有成员掌握 |
| 王国通用语 | `language.crown_common`，首版公共服务与默认对话语言 |
| 文化标签 | 为内容选择提供的非排他 stable ID，不作为人格或能力结论 |

## 4. 规则与不变量

| ID | 规则 |
|---|---|
| `REQ-WORLD-014` | 首版身份 Catalog 必须支持人类、林裔、岩裔和兽裔四类族裔，并允许任一族裔采用任一已登记文化。 |
| `REQ-WORLD-015` | 王冠溪镇必须表现至少三种跨族群共享习俗，以及每个文化传统的一项可观察差异。 |
| `REQ-WORLD-016` | 对话和内容必须区分族裔、文化、国籍、组织与个人价值观，禁止以族裔推断善恶、智力、职业或忠诚。 |
| `RULE-WORLD-018` | 族裔不授予隐藏法律地位、固定关系值或必然语言；任何机械差异必须由 RESIDENT/MAGIC owner 的显式能力定义。 |
| `RULE-WORLD-019` | 文化标签可多选并随长期生活经历变化，角色不被限制为单一“纯文化”。 |
| `RULE-WORLD-020` | 王国通用语保证公共服务可用；传承语造成的信息差必须有翻译、询问或学习路径。 |
| `RULE-WORLD-021` | 偏见可以作为角色缺陷或社会冲突出现，但叙事与系统不得把偏见陈述为 Canon 生物事实。 |

## 5. 数据与接口

`DES-WORLD-005`：发布 `AncestryCultureProfile` Catalog：

| 类别 | Stable ID | 可见/习得特征 |
|---|---|---|
| 族裔 | `ancestry.human` | 外貌跨度广；无固定文化或职业 |
| 族裔 | `ancestry.woodkin` | 林裔，常见长耳与对微光敏感的外观表现；不等于森林守誓者 |
| 族裔 | `ancestry.stonekin` | 岩裔，常见紧实体格与家族纹饰；不等于矿工 |
| 族裔 | `ancestry.beastkin` | 兽裔，具耳、尾或局部兽征；表现必须避免宠物化 |
| 文化 | `culture.crown_creek_local` | 河桥问候、共享炖锅、暴雨互助值守 |
| 文化 | `culture.forest_oath` | 采集前确认边界、记录再生周期、以结绳保存承诺 |
| 文化 | `culture.ash_delver` | 入矿同伴核名、工具传承、事故后静默守灯 |
| 文化 | `culture.roadfarer` | 商路礼价、便携饮食、以路线和故事维系远亲 |

角色身份引用 `ancestry_id`、`culture_ids[]`、`language_proficiencies[]`，具体存储由 RESIDENT owner 定义。

## 6. 正常流程

1. 新世界从四类族裔中组成 8–12 名正式居民，覆盖小镇必要职业，但职业选择不按族裔硬编码。
2. 每名居民至少具有一个文化标签与王国通用语能力，可因家庭、组织或迁徙拥有第二文化。
3. 日常中通过餐食、工作礼仪、节庆参与、称谓、服装材料和空间使用表现文化。
4. 跨文化分歧先表现为具体习俗或利益冲突，例如采集速度与森林再生记录，而不是抽象种族敌意。
5. 长期共同经历可新增本地文化标签、改变语言熟练度或形成共享习惯，不改变 ancestry。

## 7. 边界情况

- 同族裔角色可以来自不同文化并持相反立场；对话模板不得假定彼此熟悉。
- 混合家庭或收养角色可拥有多个文化标签，UI 按角色自我认同排序。
- 角色不掌握某传承语时，不能因 ancestry 自动理解；公共紧急信息必须提供通用语版本。
- 兽裔外观不得使用贬低性“驯养、主人、品种”措辞；林裔和岩裔也不得被简化为自然/矿业工具。
- 文化冲突涉及违法行为时，法律按行为和管辖处理，不按群体身份定罪。

## 8. 错误与降级

生成内容把职业、道德或语言硬绑定 ancestry 时，内容校验返回 `WORLD_IDENTITY_ESSENTIALISM`。未知文化标签不得自动创建，降级为无标签的个人习惯描述。缺少特定外观 Asset 时使用同族裔已登记的中性 fallback，不改变身份数据。

## 9. 安全与性能

身份字段只用于必要表现、角色设定和明确规则，不作为无关 AI 排序或价值评分特征。模型上下文按当前场景提供相关文化摘要，避免复制整份 Catalog。测试语料包含反刻板样例，不保留现实仇恨语料全文。

## 10. 验收标准

- 四类族裔均能生成至少两种不同职业、文化和性格的合法居民。
- 任意族裔与四个文化标签组合均通过 Schema，且不自动改变关系、权限或职业。
- 王冠溪镇至少可观察河桥问候、共享炖锅、暴雨互助值守三项共同习俗。
- 不同语言条件下存在翻译或改用通用语路径，不产生不可恢复阻塞。
- 偏见言论只记录为发言者 Belief/态度，不能进入 objective identity fact。
