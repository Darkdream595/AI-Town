AI Town · 开始游戏
====================

一、启动游戏
------------
双击「启动AI小镇.bat」，稍等片刻（首次启动最长约 1 分钟），
默认浏览器会自动打开游戏页面。

如果 Windows SmartScreen 提示「已保护你的电脑」：
点击「更多信息」→「仍要运行」。这是未签名程序的常规提示。

二、进入全屏
------------
进入游戏后按 F11，或点击界面右上角的全屏按钮。

三、退出游戏（重要）
--------------------
请始终使用以下任一方式退出，存档才会安全保存：
  1. 网页内的「保存并退出」按钮；
  2. 系统托盘（右下角）AI Town 图标菜单中的「保存并退出」；
  3. 双击「停止AI小镇.bat」（托盘不可用时）。
不要直接强制结束进程；万一发生意外退出，下次启动会自动恢复存档。

四、你的数据在哪里
------------------
所有存档与设置保存在：
  %LOCALAPPDATA%\AI-Town\
（在文件资源管理器地址栏粘贴该路径即可打开。）
游戏目录本身只读，卸载游戏 = 删除游戏目录；
删除游戏目录不会删除你的存档。

五、常见问题
------------
· 双击后没有反应：请稍候，首次启动需要准备运行环境；
  超过 1 分钟无动静时，双击「停止AI小镇.bat」后再重新启动。
· 杀毒软件提示：请将游戏目录加入杀毒软件的信任/排除列表。
· 断网可以玩吗：可以。未配置模型服务时游戏以内置智能模式运行。
· 如何迁移到另一台电脑：复制 %LOCALAPPDATA%\AI-Town\ 整个目录，
  或使用游戏内的世界导出/导入功能。

版本信息请见游戏内「关于」。
